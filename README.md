# 元龙因果链

## 简介

我曾经做过一个实验：叫全班小学生画教室的门，结果全班画成了长方形，经过我讲解透视后，全班画的没有一个是一样的了，虽然粗糙，但观察点不同的差异还是体现出来了。也就是我门可能无法找到四维时空里完全重合的“两个观测者”，这就就是因果是“四维时空+观测者”的建模，尽管他们趋向于消除不同透视下差异，得到一个稳定的概念体模型，但以观测者为参照物，则门在每个观测者眼里的时空序列完全不同，发生状态改变时的因果解释就可能不同。雷劈断了树，躲在屋檐下的张三和旷野里的李四对这件事的描述可能有差异。但当他们约定了“雷”和“树”这两个概念体后，不再向下分形或向上组合，他们的因果解释就一致了：“雷劈断了树”，不会是“很强烈的光把碳原子组成的物体烧掉了”。“果无普适”在无名流变进入观测这个阶段就已经成立了。稳定概念除了交流共指外，他可以可以保持众生的认知熵减和执念：经历千山万水，你还是我心中的你。关于你的故事才可以延续。
