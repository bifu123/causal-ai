## 简介

> “语义空间”，指的是事件节点以语义向量建立的(x,y,z)轴的空间，再加上时间稀释函数，即“语义时空”x,y,z,t)，再加上观测者主观选认连接的因果连线（我们仍然拒绝叫“图”或“边”），即“五维本体”(x,y,z,t,w)。

> 我们假设一轮对话向一个事件节点灌入50个字，双方所指、意图未充分对齐表达，此时在因果时空中由于语义密度较稀疏，其引力捕获到的关联事件距离较远或精确度差。随着双方交谈深入，灌入的内容丰富起来，在时空中捕获到的相关事件节点就更加精确，从而推到Agent的“当下”的事件视界里就如同碳基的联想和回忆，它不是检索。
