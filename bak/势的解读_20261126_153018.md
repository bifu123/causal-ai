### 1.3 当前接口字段与历史快照的区别

当前 `/api/v1/causal/click` 同时返回两组视界：

- `event_horizon`／`event_horizon_details`：完整普通事件视界，包含当前可见的因、相、果节点，不再被相过滤覆盖。
- `shi_event_horizon`／`shi_event_horizon_details`：从普通视界独立筛出的相事件势视界，只用于势计算与核对。
- `shi`／`shi_meta`：仍由相事件候选计算，非相节点不参与。

当前以 5662 为焦点、`max_eyes=100` 实测时，普通视界有 14 项，独立势视界有 3 项；势样本仍为焦点外的 5660、5661 两项，计算结果仍为 `shi=97.08`。因此，历史快照中的数值推导仍然有效，但当前阅读势视界时应使用 `shi_event_horizon_details`，不能再把普通 `event_horizon_details` 当成相事件样本列表。

## 2. 事件视界中“势”部分的解读

### 2.1 本次视界与有效样本

焦点是 5662“民主党将控制参议院。”。系统先取得完整普通视界，再从中按 `block_tag="相"`、可见性、有效向量和 `max_eyes=100` 生成独立势视界。本文历史快照中的势视界，以及当前接口的 `shi_event_horizon_details`，都只包含 5662、5660、5661 三个相事件；普通 `event_horizon_details` 在当前实现中仍保留其他因、果节点。

| serial_id | 在计算中的角色 | 距离 | 当前关系 | 关系置信度 |
|---:|---|---:|---|---:|
| 5662 | 焦点，保留在显示视界，但不进入自身样本 | 0 | — | — |
| 5660 | 焦点外候选 | 1.285922297370834 | 同向 `same` | 1.00 |
| 5661 | 焦点外候选 | 11.631278243468357 | 反向 `opposite` | 0.96 |

因此，势视界详情有三项，但 `shi_meta.sample_count=2`：焦点自身不参与自己的势计算。在当前响应中应查看 `shi_event_horizon_details`；在本文历史 JSON 中，它对应拆分前旧 `event_horizon_details` 的三项。5660 与 5662 的标题经规范化后一致，判为同向；5661 与它们只有显式否定极性相反，判为反向。

根节点 5659 和对贞节点 5663 都不是相事件，不进入本次势样本。`updated_count=29` 表示本次点击更新的个人权重记录数量，不是势候选数量；`data.survival_weight=0.6` 是 5662 在 `actor_2` 个人副本中的大股东权重，也不是势值。

### 2.2 基础势：语义叠影有多近

两个焦点外候选的平均距离为：

```text
avg_distance = (1.285922297370834 + 11.631278243468357) / 2
             = 6.4586002704195955
```

基础势为：

```text
B = clamp(100 - avg_distance, 0, 100)
  = 93.5413997295804
  ≈ 93.54
```

这与响应中的 `base_shi=93.54`、`avg_distance=6.4586` 一致。它说明两个候选在语义空间中都离焦点较近，其中 5660 尤其接近。

### 2.3 同反向干涉：不是简单按节点个数投票

距离先转为接近度，再乘关系置信度：

```text
5660：q = 1 - 1.285922297370834 / 100 = 0.9871407770262917
      w_same = q × 1.00 = 0.9871407770262917

5661：q = 1 - 11.631278243468357 / 100 = 0.8836872175653164
      w_opposite = q × 0.96 = 0.8483397288627037
```

于是：

```text
S = 0.9871407770262917
O = 0.8483397288627037
R = (S - O) / (S + O)
  = 0.07562109633867299
  ≈ 0.075621
```

虽然 `same_count=1`、`opposite_count=1`，但同向与反向不会按数量直接抵消：同向候选距离更近、置信度也更高，所以本次净干涉略偏向同向，`R` 为小幅正数。

### 2.4 最终势 97.08 如何得到

当前 `lambda=0.5`，因此：

```text
shi = round(clamp(B × (1 + 0.5R), 0, 100), 2)
    = round(93.5413997295804 × (1 + 0.5 × 0.07562109633867299), 2)
    = 97.08
```

也就是说，**97.08 主要由很高的基础对齐度 93.54 构成，同向关系又带来了小幅增强**。它不是“97.08% 的支持率”，也不是事件必然成“果”的概率，而是该观测时刻相事件语义叠影与同反向关系共同形成的瞬时势。

| 字段 | 本次值 | 解读 |

| `status` | `complete` | 本次两个候选的关系均已完成判断，不是部分观测 |
| `sample_count` | 2 | 两个焦点外有效候选；焦点不计入 |
