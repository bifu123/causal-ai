# 日志（Logs）

本目录存放项目开发过程中的思考记录与实现笔记。

## 前端资源本地化（离线 / 内网可用）

> 目标：页面不再依赖任何外网 CDN 与 Google Fonts，在无外网的内网环境也能完整运行。
> 实际落地情况：`templates/*.html` 中原先的 6 类外部引用已全部改为 `/static/...` 本地文件。

### 1. 依赖来源（npm 包 -> static 文件）

| 原外部引用 | 现在使用 | 本地文件 |
| --- | --- | --- |
| `https://cdn.tailwindcss.com`（浏览器实时编译） | `tailwindcss@3.4.17` + `@tailwindcss/forms` + `@tailwindcss/typography` 预编译 | `static/css/tailwind.min.css`（源文件 `static/css/tailwind.src.css`，配置 `tailwind.config.js`） |
| `https://unpkg.com/vis-network/...` | `vis-network@9.1.9` | `static/js/vis-network.min.js` |
| `https://cdn.socket.io/4.5.4/...` | `socket.io-client@4.5.4` | `static/js/socket.io.min.js` |
| `https://cdnjs.cloudflare.com/.../three.js/r128/` | `three@0.128.0` | `static/js/three.min.js` |
| `https://unpkg.com/easymde/...` | `easymde@2.18.0` | `static/js/easymde.min.js`、`static/css/easymde.min.css` |
| `https://cdn.jsdelivr.net/npm/marked@4.3.0` | `marked@4.3.0` | `static/js/marked.min.js` |
| `https://cdn.jsdelivr.net/npm/katex@0.16.21` | `katex@0.16.21` | `static/js/katex.min.js`、`static/css/katex.min.css`、字体 `static/fonts/katex/*` |
| `https://cdn.jsdelivr.net/npm/marked-katex-extension@5.1.13` | `marked-katex-extension@5.1.13` | `static/js/marked-katex-extension.umd.js` |
| 已在本地：d3 / 3d-force-graph / tween | `@tweenjs/tween.js@18.6.4` 补齐 | `static/js/{d3,3d-force-graph,tween.umd}.js` |
| `https://fonts.googleapis.com/css2?family=Orbitron...&family=Noto+Sans+SC...` | `@fontsource/orbitron@5.0.0`、`@fontsource/noto-sans-sc@5.0.0` | `static/fonts/Orbitron-{400,700,900}.woff2`、`static/fonts/NotoSansSC-{300,400,500,700,900}-{latin,chinese-simplified}.woff2`，样式 `static/css/fonts.local.css` |

要点：

- **字体**：`fonts.local.css` 里的 `font-family` 名称（`Orbitron`、`Noto Sans SC`）与原 Google Fonts 完全一致，
  页面内联样式无需改动。中文使用 `chinese-simplified` 全量子集（每个字重 1 个 woff2，约 1.5MB），
  `latin` 子集单独给出 `unicode-range`，浏览器会按需只加载用到的字重。
- **KaTeX 字体**：`katex.min.css` 中的 `url(fonts/...)` 已重写为 `url(/static/fonts/katex/...)`，
  60 个字体文件已随包放入 `static/fonts/katex/`。
- **EasyMDE**：`easymde.min.js` 中仅有一处 `https://maxcdn.bootstrapcdn.com/font-awesome/...` 的
  “缺失图标时自动注入”逻辑，已改为本地路径；本项目未使用 Font Awesome 图标（工具栏为文字/内置 SVG），
  `spellChecker` 也未启用，因此不会发起任何外部请求。
- **Tailwind**：CDN 版是在浏览器端实时扫描 DOM 生成样式的；改为预编译后，`tailwind.config.js` 的
  `content` 已包含 `templates/2d_main.html`、`templates/3d_main.html`、`static/js/2d_main.js`。
  **今后在模板里新增 Tailwind 类名，需要重新执行 `npm run build:css`**，否则不会生成对应样式。

### 2. 常用命令

```bash
# 安装前端依赖（package-lock.json 已提交，registry 可用 npmmirror 加速）
npm install --registry=https://registry.npmmirror.com

# 重新编译 Tailwind（修改模板里的 Tailwind 类名后必须执行）
npm run build:css

# 重新抓取 / 生成自托管字体（仅在字体缺失或需要换字体时执行）
npm run fonts

# 自检：模板是否还引用外网资源、静态文件是否存在、CSS 内字体路径是否可解析
npm run check:assets

# 自检：本地 UMD 库能否正确挂载全局变量（vis / io / THREE / TWEEN / EasyMDE / marked）
npm run check:libs

# 自检：marked + katex + marked-katex-extension 组合渲染
npm run check:katex

# 自检：Tailwind 产物是否覆盖模板中用到的工具类
npm run check:tailwind
```

### 3. 已知限制

- 字体、Tailwind、第三方 JS 都是**随仓库提交的构建产物**（共约 12MB），
  重新生成需要能访问 npm registry / jsdelivr 的网络环境。
- `fonts.googleapis.com` / `fonts.gstatic.cn` 在部分网络下不可达，因此字体脚本改为读取
  `@fontsource` 包内的稳定子集（`chinese-simplified` + `latin`），而不是逐片抓取 Google 的 unicode-range 切片。
- `static/js` 中的 `d3.min.js`、`3d-force-graph.min.js` 原本即本地文件，本次未更换版本。
- `static/js/3d_main - 副本.js` 为历史备份文件，页面未引用，可自行清理。
